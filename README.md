# Ke (Wade) Yang — Academic Homepage

A responsive academic homepage with selected projects, education, experience, and a downloadable CV. Built with plain HTML and CSS; no package installation or build step is required.

## GitHub Pages

Expected website address: https://wade-yyk.github.io/About-me/

In repository **Settings → Pages**, use **Deploy from a branch**, choose **main**, select **/ (root)**, and save. The `.nojekyll` file allows the static files to be served directly.

## Update the page

- Edit `index.html` for biography, projects, education, and links.
- Edit `styles.css` for colors, typography, and layout.
- Replace `assets/Ke_Yang_CV.pdf` when the CV changes, keeping its filename.
- Update the footer date after content changes.
- If the website address changes, update both the canonical URL and `og:url` in `index.html`.

Open `index.html` in a browser for a local preview. All styles, icons, and the CV use relative paths compatible with this repository's Pages address.

Official setup guide: https://docs.github.com/en/pages/quickstart
